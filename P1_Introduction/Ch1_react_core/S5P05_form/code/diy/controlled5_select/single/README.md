# React 受控下拉框示例

这是一个基于 Create React App 的 React 示例项目，演示如何使用受控组件实现单项课程下拉选择。

## 功能

- 下拉框提供 HTML、CSS、JS、Vue 和 React 五个选项。
- 默认选中 React，选择变化时会在浏览器控制台输出当前选项。
- 点击“提交”后，会在浏览器控制台输出待提交的选项。

## 环境要求

- Node.js 和 npm

## 开始使用

安装依赖：

```bash
npm install
```

启动开发服务器：

```bash
npm start
```

应用默认运行在 [http://localhost:3000](http://localhost:3000)。

## 其他命令

```bash
npm test       # 运行测试
npm run build  # 构建生产版本
```
