# React 非受控下拉框示例

这是一个基于 React 和 Create React App 的小型示例项目，演示如何使用 `ref` 读取非受控 `<select>` 的当前选项。

## 示例功能

- 下拉框提供 HTML、CSS、JavaScript、Vue 和 React 选项。
- 默认选中 React。
- 点击“提交”后，当前选项的 `value` 会输出到浏览器开发者工具控制台。

## 环境要求

- Node.js
- npm

## 启动项目

在项目根目录运行：

```bash
npm install
npm start
```

开发服务器启动后，访问终端中显示的本地地址。

## 可用命令

```bash
npm start      # 启动开发服务器
npm test       # 运行测试
npm run build  # 构建生产版本
```

## 主要文件

- `src/App.js`：下拉框示例组件。
- `src/index.js`：React 应用入口。
- `public/index.html`：HTML 页面模板。
