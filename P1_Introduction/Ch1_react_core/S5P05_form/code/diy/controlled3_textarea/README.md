# React 汇率换算示例

这是一个基于 `React` 的人民币（`RMB`）与美元（`USD`）双向换算示例。页面包含两个金额输入框，修改任一输入框时，另一个输入框会根据汇率同步更新。

## 功能说明

- 初始时人民币和美元金额均为空。
- 编辑人民币金额时，按配置的人民币兑美元汇率计算美元金额；编辑美元金额时则反向计算人民币金额。
- 汇率在 [src/utils.js](./src/utils.js) 中配置。目前启用的示例汇率为 `1 USD = 7.3255 RMB`、`1 RMB = 0.1365 USD`，不是实时汇率。
- 换算结果四舍五入并显示为小数点后 4 位。输入为空或无法解析为数字时，另一侧显示为空。

## 运行项目

请先安装 `Node.js` 和 `npm`。在项目根目录运行：

```bash
npm install
npm start
```

开发服务器启动后，在浏览器打开终端中显示的本地地址（通常为 `http://localhost:3000`）。

## 常用命令

```bash
npm test       # 运行测试
npm run build  # 构建生产版本
```

## 代码结构

- `src/App.js`：保存当前输入的金额及币种状态，并协调两个换算输入框。
- `src/components/Money.jsx`：渲染带币种标题的金额输入框。
- `src/utils.js`：定义汇率及金额转换、结果格式化逻辑。
