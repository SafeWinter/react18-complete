# React 状态切换示例

这是一个使用 `React` 编写的简单交互示例。页面通过组件状态控制警告信息的显示与隐藏。

## 页面使用

- 页面初始时警告信息隐藏，按钮显示 `Show`。
- 点击 `Show` 后显示 `Warning!`，按钮文字变为 `Hide`。
- 点击 `Hide` 后警告信息再次隐藏，按钮恢复为 `Show`。

## 运行项目

需要先安装 `Node.js` 和 `npm`。在项目根目录执行以下命令安装依赖并启动开发服务器：

```bash
npm install
npm start
```

开发服务器启动后，在浏览器中打开终端显示的本地地址（通常是 `http://localhost:3000`）。修改代码后，页面会自动重新加载。

## 其他命令

```bash
npm test       # 运行测试
npm run build  # 构建生产版本
```
