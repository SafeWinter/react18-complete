# React 状态提升示例（新版文档）

> 参考文档：[状态管理：在组件间共享状态](https://zh-hans.react.dev/learn/sharing-state-between-components)

这是一个使用 `React` 编写的简单交互示例，介绍哈萨克斯坦城市阿拉木图。页面包含“关于”和“词源”两个内容面板，同一时间只展开一个面板。

## 运行项目

需要先安装 `Node.js` 和 `npm`。在项目根目录执行：

```bash
npm install
npm start
```

开发服务器启动后，在浏览器中打开终端显示的本地地址（通常是 `http://localhost:3000`）。修改代码后，页面会自动重新加载。

## 页面使用

- 页面打开时默认展开“关于”，显示阿拉木图的人口和历史简介。
- 点击“词源”下方的“显示”按钮，查看城市名称的来源及苹果相关介绍。
- 展开一个面板后，另一个面板会收起；点击收起面板的“显示”按钮即可切换内容。

## 其他命令

```bash
npm test    # 运行测试
npm run build  # 构建生产版本
```
